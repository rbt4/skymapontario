Privacy,
kept simple.

SkyMap Ontario does not require an account and does not operate an advertising profile. The website and app request public weather information needed to display the selected location and forecast.

Live location

On first launch SkyMap asks once for your device location so the forecast pinpoint starts where you are. You can also tap My location at any time. The coordinates are used to request nearby public weather data and are stored only in the browser's or app's local storage so SkyMap reopens at the same point. On Android the saved point is also used for background forecast refreshes on the device. SkyMap does not maintain a user-location server.

Weather evidence

For the active pinpoint SkyMap requests Environment and Climate Change Canada radar, radar extrapolation, HRDPS and REPS guidance, city-page forecasts, weather alerts and AQHI observations, plus point guidance from four forecast families and ensembles through Open-Meteo. A visit check also reads a small ring of nearby points to describe the surrounding rain area. These are ordinary public-data requests made for the active location.

Place search

When you type in place search, the place name is sent to Open-Meteo's public geocoding service to return Ontario matches. A selected place may be stored locally so SkyMap can reopen there.

Local forecast memory

SkyMap keeps a bounded forecast memory in your browser or app storage: recent model responses, the previous forecast for a point (to say whether an event shifted earlier or later), load-speed measurements, and personal verification statistics that compare past forecasts with later official observations. This information stays on the device and is never uploaded. Clearing site data, or removing the Android app, deletes it.

Published verification data

SkyMap reads a public, machine-generated forecast-verification summary from the SkyMap Ontario GitHub repository (raw.githubusercontent.com). Nothing about you is sent beyond an ordinary web request.

Shared visit cards

When you choose Share large image or Share short GIF, SkyMap creates the file on your device from the selected place, visit window and public weather guidance. SkyMap does not upload the generated file. It is passed only to the app or person you select in your device's share sheet.

Public services

Weather and place-search requests are sent to public services used by the app, including Environment and Climate Change Canada, Open-Meteo, CARTO map tiles and GitHub. Those services may receive ordinary request information such as IP address and browser or app user agent under their own policies.

Ko-fi and external links

Ko-fi, GitHub and official-source links open external websites. SkyMap does not receive payment details from Ko-fi.

Contact

Project questions can be raised through the SkyMap Ontario GitHub repository.
