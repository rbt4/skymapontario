# Experiment flags

This first lab intentionally has no user-facing switches. The experiment should be judged as a default experience, not configured into usefulness.

Internal concepts under evaluation:

- continuous observed-to-predicted timeline;
- exact-point answer overlay;
- persistent precipitation-event identity;
- source-weighted event declaration;
- timing-spread confidence;
- locally stored forecast-shift memory;
- quiet failure states when one source is unavailable.
