# Changelog

## 19.0.0-experimental.1 — 2026-07-27

- Added the isolated SkyMap Future Lab.
- Added one continuous timeline spanning measured radar, official radar extrapolation, and HRDPS guidance.
- Added an exact-point precipitation answer that remains visible over the map.
- Added weighted GEM, IFS, GFS, and AIFS point consensus through eight days.
- Added persistent precipitation-event windows and the seven-day RainLine.
- Added forecast-memory language for stable, earlier, later, and faded events.
- Added source-health and evidence views with explicit partial-failure states.
- Added automatic geolocation, place search, map-point selection, responsive layout, and installable metadata.
